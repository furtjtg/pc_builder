# Конфигуратор ПК

Веб-страница для подбора комплектующих и сборки системного блока по прайс-листу поставщика (XLS / XLSX). Работает полностью в браузере, без сервера и внешних библиотек — файлы можно открыть напрямую.

## Для чего это

Страница помогает собрать конфигурацию ПК «под заказ»:

- **Загрузка прайс-листа** — загружается файл поставщика (XLS или XLSX), из него автоматически распознаются компоненты: процессоры, видеокарты, материнские платы, память, SSD/HDD, блоки питания, кулеры и корпуса.
- **Подбор совместимых компонентов** — при выборе процессора автоматически отфильтровываются подходящие материнские платы (по сокету и поколению памяти), память, блоки питания (по потреблению), кулеры (по TDP). Проверяются «слепые зоны» совместимости: встроенный блок питания корпуса, длина видеокарты, высота кулера и размер радиатора СЖО.
- **Расчёт стоимости** — показывается итоговая сумма сборки и сумма с наценкой для клиента (процент наценки настраивается).
- **Сохранённые сборки** — до 4 вариантов сборок сохраняются в памяти в рамках сеанса (до обновления страницы). Сохранённую сборку можно вернуть в конфигуратор одной кнопкой или удалить.
- **Экспорт** — печать сборки для клиента (цены с наценкой, можно сохранить в PDF) и выгрузка заказа в Excel (.xls) для отправки поставщику (позиции повторяются строками исходного прайса).

## Структура проекта

| Файл        | Назначение                                                        |
|-------------|-------------------------------------------------------------------|
| `index.html`| Разметка страницы (панель действий, конфигуратор, результаты)     |
| `style.css` | Оформление, адаптивность для небольших окон и мобильных устройств |
| `script.js` | Логика: парсинг прайса, фильтры совместимости, расчёт, сохранение сборок, экспорт |
| `icons/`    | Графические файлы (при наличии)                                   |

## Как пользоваться

1. Откройте `index.html` в браузере (Chrome, Edge, Firefox и т.п.).
2. Нажмите **«Загрузить прайс-лист (XLS/XLSX)»** и выберите файл прайса.
3. Выбирайте компоненты в выпадающих списках — совместимые позиции подбираются автоматически.
4. Нажмите **«Рассчитать»**, чтобы увидеть итоговую сумму и предупреждения о несовместимости.
5. При необходимости сохраните сборку (до 4 шт.) или выгрузите заказ: **«Для клиента»** (печать/PDF) или **«Выгрузить Excel»**.
6. Кнопка **«Сбросить»** очищает текущий выбор.

## Возможности

- Распознавание прайсов разных поставщиков (XLS и XLSX) без сторонних библиотек
- Автоматическое определение характеристик по названию: сокет, поколение памяти, TDP, потребление и длина видеокарты, мощность БП, параметры корпуса
- Пометка позиций из резерва (скрыты по умолчанию, включаются чек-боксом «Резервы»)
- Наценка на итог для показа клиенту (округляется до 10 руб. в большую сторону)
- Сохранённые сборки в рамках сеанса (до 4)
- Компактный вид для небольших окон браузера (от 800×600); адаптация для мобильных устройств

## Технические детали

- Чистые HTML/CSS/JavaScript, без сборки и зависимостей
- Парсинг XLS — собственная реализация (чтение бинарного формата), XLSX — распаковка ZIP в браузере
- Данные прайса хранятся в памяти страницы; при обновлении страницы загруженный прайс и сохранённые сборки сбрасываются
